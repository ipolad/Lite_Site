AI agents now change real business data. What they were asked, what they report and what they actually did can be three different things. lite catches the moment they stop matching, and tells the person in charge.

SAID ≠ DID

Silent failure

The agent says "done". Nothing changed in the system.

DID ≠ SAID

Unclaimed change

Data changed that the agent never reported.

DID ≠ ASKED

Drift

The agent did more than it was asked, or something else.

Why it gets worse

Small errors add up over long tasks.

If an agent gets each step right 99% of the time, a 50-step task comes out fully right only about 60% of the time. That's simple math, not a survey.

Agents are taking on longer tasks, with more steps and fewer human checkpoints. A quarter of them can already start other agents.

The platform

Catch it. Fix it. Make sure it doesn't come back.

One platform in three modules. Each one reuses the data Radar already collects.

Phase 1 · Now

liteRadar

Detects the gap and alerts the right people.

  • Compares asked, said and did on every agent task
  • Instant alert to the person in charge of the agent
  • Daily summary to the executive in charge
Detective control
Phase 2 · Next

liteRewind

Rolls back the wrong change.

  • Shows exactly what changed, before and after
  • A human approves; lite reverses the change
  • Flags what can't be undone and pauses the agent
Corrective control
Phase 3 · Later

liteCoach

Retrains the agent not to repeat it.

  • Every confirmed gap becomes a lesson
  • Feeds agent instructions, rules and test cases
  • Gap rate per agent goes down over time
Preventive control
lite Rewind

Undo the wrong change, with a human in control.

ReversibleA field or status changeOne-click undo after approval
CompensableA refund or payment already sentlite proposes the reversing transaction
IrreversibleAn email sent, data sharedEscalate and pause the agent

Each undo uses a temporary, narrow permission and is logged as evidence.

lite Coach

Turn every confirmed gap into a lesson.

  • Agent instructionsClearer rules, like "never change customer tier during a refund"
  • Guardrail rulesBlock the pattern before it runs again
  • Test casesReplay the case before every new agent version
  • Training dataFine-tuning examples, where you own the model

Each agent's gap rate falls over time, and lite shows the trend to the executive.
