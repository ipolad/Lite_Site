# lite website

Static one-page site for lite, the Agents Integrity Platform (getlite.ai).

- `index.html`: the whole site (HTML, CSS and JS in one file; fonts from Google Fonts)
- `favicon.svg`: tab icon
- `vercel.json`: tells Vercel to serve the files as-is, with no build step

## Lead form
Submissions go to itzik@getlite.ai through FormSubmit (`CONTACT_EMAIL` at the top of the script in `index.html`).
The first submission on the live site sends a one-time activation email to that inbox; confirm it and leads start arriving.
